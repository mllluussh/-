# Камень, ножницы, бумага на Java

агай мен камень ножницы бумага оюнун алдым Javaдан: Бул менин Java боюнча оюнум: компьютерге каршы консолдук «Таш, кайчы, кагаз» оюну. 3 жеңишке чейин ойнойбуз, ал эми аягында программа бүт оюн боюнча кандай жүрүштөр болгонун статистика катары көрсөтөт.

## Кантип иштетүү
Java (JDK) орнотулган болушу керек. Файл турган папканы терминалда ачып, мындай жазабыз:
javac RockPaperScissors.java
java RockPaperScissors
Эгер консолдо орусча тамгалардын ордуна түшүнүксүз белгилер чыкса Windows'то ушундай болот, иштеткенге чейин chcp 65001 бу жазабыз да .
## Кантип ойнойт
 Сан киргизебиз: `1` таш, `2` кайчы, `3` кагаз
 `0` бассак, оюндан чыгасың
  Тең чыкса, раунд саналбайт, кайра ойнолот
  3 жолу биринчи уткан, матчты утат
  Матчтан кийин дагы ойносо болот (`д` же `н`)
  Эгер тамга, бош сап же тизмеде жок сан киргизсек, программа токтоп калбайт, кайра жаз деп  суранат.
  ## Кодтун ичи 
  Өзгөрмөлөр жана типтер: упай үчүн int, статистикадагы пайыздар үчүн double, киргизүү үчүн String, playAgain сыяктуу желекчелер үчүн boolean. Ошондой эле final аркылуу константалар бар (жүрүштөрдүн коддору жана жеңиштин саны).
Шарттар: раунддун жыйынтыгы үчүн if / else if / else, оюнчунун киргизгенин иштетүү үчүн switch, ал эми ким утканын текшерүүдө &&, || жана !.
Циклдер: оюн жүргөн башкы while цикли, статистиканы чыгаруу үчүн for, ошондой эле break жана continue (мисалы, тең чыкканда раунд continue аркылуу кайра ойнолот).
Массивдер: бир өлчөмдүү moveCount (ар бир жүрүш канча жолу тандалганы) жана эки өлчөмдүү pairs (оюнчунун кайсы жүрүшү компьютердин кайсы жүрүшүнө каршы болгону).
Методдор: код параметрлери жана return менен методдорго бөлүнгөн, ошондо main чоң болбойт. Мисалы, getRoundResult ким утканын кайтарып берет.
Оюн логикасы: компьютердин жүрүшү үчүн Random, киргизүү үчүн Scanner.
## Эмнеси кыйын болду
Эң кыйыны киргизүүнү туура текшерүү болду, ар кандай тамгадан оюн токтоп калбашы үчүн. `nextInt()` менен кылайын дегем , бирок ал тексттен ката кылып, ошондуктан бүтүн сапты `nextLine()` менен жазып, `switch` менен карайбыз . Дагы тең чыкканда раундду санабоо жөнүндө ойлонууга туура келди, анан `continue` жардам берди.
